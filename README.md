# HomePilot AI

HomePilot AI is a beginner-built real estate AI assistant.

## Version 1 features

- Buyer and seller modes
- Property information form
- AI-generated property analysis
- Secure Gemini API connection through a backend

## Security

The Gemini API key will not be stored in this GitHub repository.

The website will connect to a Cloudflare Worker, and the Worker will securely call the Gemini API.
